# Taller Titanic

Landing simple per compartir l'acces al taller a Google Colab.

## Obrir en local

Pots obrir `index.html` directament al navegador o aixecar un servidor rapid,
per exemple:

```bash
npx serve .
```

## Desplegar a Vercel

1. Puja aquest repositori a GitHub.
2. Entra a [Vercel](https://vercel.com/) i crea un projecte nou important el repo.
3. Vercel detectara que es una web estatica. No cal configurar cap build.
4. Desplega.
5. A `Settings > Domains` pots assignar un domini mes facil de recordar.
